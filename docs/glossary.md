# Glossaries

## Terms

### API

- Plural: APIs
- Exp: Application Programming Interface/s

A set of features and rules that exist inside a software program (the application) enabling interaction with it through software - as opposed to a human user interface. The API can be seen as a simple contract (the interface) between the application offering it and other items, such as third-party software or hardware.

### Argument

- Plural: Arguments
- Abbr: Arg / Args

values passed as input to a function.

```py
argument1 = 10
argument2 = 194

def  add(parameter1, parameter2):
    x = parameter1 + parameter2
    print(x);

add(argument1, argument2)
```

### Hash

- Plural: Hashes
- Abbr: N/A

A hash is a fixed-length string of numbers and letters generated by a mathematical algorithm (a hash function) from an input of any size.

- Key features:

      1. The exact same input always produces the exact same hash output.

      2. No matter how large or small the input is, the resulting hash is always the same size.

      3. You cannot reverse to get the original data from the hash value.

      4. Even a tiny change result in a drastically different output

### Parameters

Parameters are named variables declared as part of a function. They are used to reference the arguments passed into the function.

```py
argument1 = 10
argument2 = 194

def  add(parameter1, parameter2):
    x = parameter1 + parameter2
    print(x);

add(argument1, argument2)
```

### Repository

- Plural: Repositories / Repos
- Abbr: Repo

A repository is a place, container, or storage location where things such as physical items, data, files, or information are kept (organized)

!!! info "It is not limited to non-living things, a person herself can be referred as a repository of "informations". "

### Tag

- Plural: Tags
- Abbr: N/A

A piece of string that acts as a label, marker, or instruction. It greatly depends on the context it is referred in therefor, it does not have a proper definition on its own.
